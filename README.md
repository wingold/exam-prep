# 考证刷题助手（exam-prep）

本地优先的考证刷题工具：**网页免安装（PWA，可装到桌面并离线使用）+ 安卓 APK** 双端，题库与数据全部存在你自己的设备和网盘里——无账号、无服务器、无埋点。支持 AI 讲题、PDF 讲义出题、错题归因、间隔重复、考证进度台账，以及基于坚果云等网盘的免费双端同步。

> 设计文档见 [docs/PRD.md](docs/PRD.md)。

---

## 功能明细

### 题库管理
- **多格式导入**：JSON / Excel（.xlsx .xls .csv）/ Word（.docx）/ TXT，导入前可预览确认
- **PDF 讲义 AI 出题**：自动提取文字 → 按「第x章/专题」切章 → 逐章调用你的模型把知识点改编成题（核心考点自动标"重点"）→ 预览入库；支持后台生成 + 全站悬浮进度球
- **重点标记**：题目支持 `difficulty: "重点"` 字段，练习/组卷可"只做重点题"
- **题型对齐自考卷**：单选 / 多选 / 判断 / 填空 / 名词解释 / 简答 / 论述 / 材料。客观题自动判分，主观题交卷后对照参考答案自评三档（答对 / 答一半 / 没答出来），不会被误判进错题本

### 练习
- 五种模式：顺序 / 随机 / 章节专项 / 未做题快练 / 记忆复习
- 即时判分、正确答案与解析、可选"只做重点题"
- 答错可标注错因（粗心 / 不会 / 审题 / 没时间）
- 答题后可「加入记忆卡」进入间隔复习队列

### 模拟考试
- **按真题卷结构组卷**（默认）：卷面模板按科目自动匹配——
  行政法学（00261）单选 30×1 + 多选 5×2 + 名词解释 5×3 + 简答 3×5 + 论述 1×10 = 80 分；
  城市管理学（01680）单选 20×1 + 多选 10×2 + 简答 5×5 + 论述 2×10 = 85 分（本科无名词解释）；
  公共部门人力资源管理（03450）单选 15×2 + 多选 5×2 + 名词解释 5×3 + 简答 4×5 + 论述 1×10 + 案例分析 1×15 = 100 分（31 题，2025 年起卷面）；
  同科的 2024 年及以前旧卷面（单选 10×1 + 多选 5×2 + 名词 5×4 + 简答 5×6 + 论述 2×15 = 100 分，27 题，无案例）单独保留一套模板，
  题库名带「2024年10月」等年份标记时自动切换，不影响新卷面。
  材料题／案例题主观性太强，不参与组卷；题库缺哪类题会先提示缺几道，不静默少给
- 也可切「自定义题量」，只抽重点题、按章节筛选
- 考试中：答题卡、标记存疑、剩余时间、到时自动交卷
- **答案公布时机可选**：「交卷后统一公布」（默认，模拟真实考试）或「每题作答后公布」——后者做完一题点「看答案」就能当场判对错、看解析，主观题对照参考答案自评后再进下一题，适合边练边巩固；公布后本题锁定，不能改答案
- **中途可续考**：答案、标记、自评与已公布进度实时暂存，关掉应用/切走再回来会提示恢复；倒计时按真实时间算，超时按已答内容交卷
- 交卷报告：得分（满分随卷面模板，不一定是 100）、客观题正确率、分章节表现、与历史平均对比
- **逐题答案与解析**：报告里把所有题目摊开——题干、全部选项（正确答案标绿、你选错的标红）、我的作答、正确答案、解析；可按「全部 / 错题 / 主观题」筛。答对的也能回看巩固，不用等错题本
- **主观题自评**：名词解释 / 简答 / 论述没有唯一表述，在题目下方对照参考答案定档（答对 100%、答一半 60%、没答出来 0%），分数实时更新；「答对了」不进错题本。还有主观题没评时，报告顶部会明确提示当前分数只含客观题与已评部分

### 错题本
- 答错自动收录；**错因归类**，可按错因筛选并开启**专项练习**
- **是否掌握由记忆排期判定**（连对 4 次或间隔满 21 天自动移出），也可手动标记掌握 / 重新纳入；错因分布统计

### 复习记忆（间隔重复）
- 答错自动入记忆队列，**次日 0 点才到期**（当天做错的题当天不再重考，不和错题本重复）
- 也可手动加卡 / 一键把错题本全部入队（手动加卡不打乱已有排期，也不扣易度）
- 「不认识 / 模糊 / 认识」三键评分，按钮上直接显示**下次几天后**；简化 SM-2 调度
- **考试日封顶**：单卡间隔不超过「距最近考期天数 ÷ 3」，保证考前每张卡还能见 2–3 次
- 首页与练习页显示今日到期卡片数；没有到期卡时显示最近一批的到期日
- **未来 7 天负载图**：首页把每天的到期量画出来，排期不再是黑箱
- **总开关**：设置页可关掉「答错自动入队」，只留错题本；手动加卡与已有排期不受影响

### 统计
- 近 14 天正确率趋势
- 章节掌握度（最弱置顶）+ **AI 针对薄弱出题**（按薄弱章节与近期错题生成专项题库）
- 错因分析、分题库刷题进度、模考历史
- **本周 vs 上周**：分章节正确率对比，下降 ≥10 个百分点标红点名

### AI 能力（接入你自己的模型）
- 通用 OpenAI 兼容接口（DeepSeek / 通义 / Kimi / Ollama 本地等），Key 只存本机
- **AI 讲题**：答完题流式讲解（Markdown 渲染）
- **AI 弱项出卷**、**PDF 讲义出题**（见上）

### 考证进度台账
- **证书档案**：名称与报考机构可编辑（当前只维护一个证书，科目与考期挂在它下面）
- 科目台账：状态（未报考/已报考/已通过/未通过）、合格分、**成绩录入**
- 考期管理：考试日、报考截止日；每期报考科目勾选
- 总览仪表盘：**考期倒计时**、已过/待考科目数、各科复习进度条、今日学习概览
- 已通过科目自动归档折叠

### 同步与数据
- **本地优先**：全部数据存 IndexedDB；设置页一键导出/导入 JSON 备份
  - 桌面网页版：直接下载到浏览器下载目录
  - 手机 APK：写进应用缓存后弹出**系统分享面板**，在那里选「保存到文件」落到下载目录（Android WebView 不支持 `<a download>`，所以不能照搬浏览器写法）
- **WebDAV 双端同步**（坚果云等）：记录级"谁新用谁"合并 + **删除墓碑**，不互相覆盖、也不会把删掉的东西带回来
  - 删除会写一条墓碑随同步传播，另一台设备同步后同样删掉；墓碑保留 180 天后自动清理（过期后极久未同步的旧设备再上网，可能复活 180 天前删的记录）
  - 打开应用 2.5 秒后自动同步；作答后延迟 20 秒合并触发（交卷后 10 秒）；前台每 30 分钟一次；也可手动「立即同步」
  - **失败不再静默**：侧栏页脚 / 手机「更多」面板 / 设置页都显示「已同步 13:20」或「同步失败 · 见设置」，超过 3 天没成功会变色提醒
  - 内置「测试连接」（目录检测 + 写探针，精确定位 401/404/409）
  - Web 端自动走同源代理；**APK 走原生网络直连，无需任何代理**

> 换手机 / 卸载重装前，务必先到设置页点一次「立即同步」并看到成功提示——云端只保存「上次成功同步那一刻」的快照，之后新增的记录还在本机。

### 界面
- 桌面侧栏 + 手机底栏导航；手机端进度台账为卡片布局，宽表格卡内横滑
- AI 后台任务**悬浮进度球**：全站可见、可拖动、点开看详情、完成自动提醒

## 使用说明

### 快速开始

**网页版**

- 在线版：<https://wingold.github.io/exam-prep/>（GitHub Pages，每次推送 `main` 自动构建）
  - 仓库首次部署需在 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**（只需一次；之后由 `.github/workflows/pages.yml` 自动部署）
- 首次联网打开一次后，Service Worker 会缓存应用外壳与静态资源，之后断网也能进首页、刷题、看统计（AI 讲题与同步仍需网络）
- 桌面 Chrome / Edge 地址栏右侧会出现「安装」，手机浏览器菜单里可选「添加到主屏幕」，装完就是独立窗口，不再有地址栏

**网页版（本地开发）**
```bash
npm install
npm run dev        # http://localhost:5174
npm run preview    # 同样是 http://localhost:5174（构建产物预览）
```
生产构建：`npm run build`（产物在 `dist/`，任意静态服务器可托管；注意 WebDAV 同步在纯静态托管下需自建 Worker 代理，见 `cloudflare-worker.js`）。

> **端口别改。** 浏览器按「协议 + 域名 + 端口」隔离 `IndexedDB` / `localStorage`，换端口或改用 IP（如 `127.0.0.1` 换成 `10.x.x.x`）看到的都是**另一份空数据**，题库、作答记录、WebDAV 与 AI 配置全部要重来——原来的数据并没有丢，回到旧地址即可。所以 `dev` 与 `preview` 都用 5174，并设了 `strictPort`：端口被占用时直接报错，而不是悄悄换到 5175 让你以为数据没了。同理，预览不能用 `--port 4173` 之类的参数覆盖。

**安卓 APK**
- 从 Release 下载安装，或自行构建（见下文「构建 APK」）。

### 第一次使用（建议顺序）

1. **建台账**（进度页）：添加科目（名称、合格分）→ 添加考期（考试日、报考截止）→ 给考期勾选报考科目
2. **导题库**（题库页）：点「+ 导入题库」选文件 → 预览无误 → 归属科目（可选）→ 确认导入
   - Excel 表头需含：`题干`、`选项A`…`选项F`、`答案`、`题型`、`解析`、`章节`、`难度/重点`（列名模糊匹配）
   - JSON 格式示例见 [`examples/sample-bank.json`](examples/sample-bank.json)
3. **（可选）同步**（设置页，坚果云三步）：
   - 地址填根目录 `https://dav.jianguoyun.com/dav/`（或自建文件夹）——**不要**填网页版链接
   - 密码用**应用密码**（坚果云网页版 → 头像 → 账户信息 → 安全选项 → 生成），不是登录密码
   - 先点「测试连接」，显示"可正常读写"后再「立即同步」；手机 APK 同配置一次即可
4. **（可选）AI 配置**（设置页）：填 Base URL（含 `/v1`）+ API Key + 模型名，AI 讲题 / 弱项出题 / PDF 出题共用
5. **开刷**：练习或模考 → 错题本复习 → 统计页看薄弱章节

### 常用操作速查

| 想做什么 | 去哪里 |
|---|---|
| 练题 | 练习页 → 选题库 → 选模式 → 开始 |
| 模拟考试 | 考试页 → 组卷设置 → 开始 → 交卷看报告 |
| 集中消灭某类错题 | 错题页 → 点错因标签 → 开始专项练习 |
| 今天该复习什么 | 首页「记忆复习（N）」或 练习页 → 记忆复习 |
| 把讲义 PDF 变成题库 | 题库页 →「PDF 讲义 AI 出题」（可离开页面，进度球跟进） |
| 按弱项让 AI 出题 | 统计页 →「AI 针对薄弱出题」 |
| 换手机 / 数据搬家 | 设置页 → 导出备份 JSON → 另一端导入；或配好 WebDAV 自动同步 |

### 常见问题（FAQ）

**Q：同步报 401？** 应用密码不对或带了空格——重新生成应用密码并复制完整；测试连接会给出明确提示。

**Q：同步报 404/409？** 目录不存在。改用根目录 `https://dav.jianguoyun.com/dav/`，或先在网盘网页版建好文件夹。

**Q：手机 APK 要配跨域代理吗？** 不需要。代理只影响网页版；APK 走原生网络直连，"跨域代理"留空。

**Q：PDF 出题报"提取不到文字"？** 该 PDF 是扫描版/图片版，目前不支持 OCR。请改用能选中复制文字的 PDF，或先转成 Word/文本后用「导入题库」。

**Q：AI 相关功能点了一直不动/报错？** 先到设置页确认模型配置；模型生成每章约半分钟，期间可离开页面（右下角进度球跟进）。

**Q：关掉应用后台生成会中断吗？** 会。悬浮球是应用内后台，彻底关闭浏览器/App 会中断生成，重新发起即可。

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | Vue 3 + Vite（哈希路由） |
| 存储 | IndexedDB（Dexie），本地优先 |
| PDF 解析 | pdf.js v4（legacy build） |

| 打包 | Capacitor（安卓 APK，CapacitorHttp 原生网络） |

### 构建 APK

要求：Node 20+、Android SDK（含 platform 36 与 build-tools 36）、**JDK 21**（JDK 17 编译不过，JDK 25 会触发 Gradle Groovy 兼容问题）。

```bash
npm run build
npx cap sync android
npm run check:assets           # 必做：确认 dist 真的同步进了 Android 工程
cd android
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

> `cap sync` 偶发失败（文件被 Gradle 或杀毒软件占用），而随后的 `gradlew` **仍然是 BUILD SUCCESSFUL**——只是打进包里的还是上一版界面。`npm run check:assets` 就是用来卡这一步的。

**自检**：`npm test` 会跑两个脚本——`verify-srs.mjs`（排期与掌握判定，19 项）和 `verify-bank-roundtrip.mjs`（题库导出回导字段一致性）。

**版本号**：唯一来源是 `package.json` 的 `version`。Android 侧自动派生 `versionName`（如 `1.7.0`）与 `versionCode`（`major*10000 + minor*100 + patch`，如 `10700`），界面「关于」里的版本也取自同一处——不要再手改 `build.gradle`。

**签名出包（release）**：

```bash
cd android
./gradlew assembleRelease
# 产物：android/app/build/outputs/apk/release/app-release.apk
```

签名配置读 `android/keystore.properties`（**不入库**），格式：

```properties
storeFile=C:/path/to/your-release.jks
storePassword=******
keyAlias=your-alias
keyPassword=******
```

没有该文件时 `assembleRelease` 仍能构建，但产物未签名，无法覆盖安装已发布的版本。密钥一旦公开使用就**不可更换**（更换后旧版本无法覆盖升级，用户本地数据会随卸载丢失），务必备份到项目目录之外。

## 目录结构（关键部分）

```
src/
  views/            # 各页面（总览/进度/题库/练习/考试/错题/统计/设置）
  components/       # 悬浮进度球、AI 讲题面板等
  db.js             # Dexie 表结构、导出导入
  sync.js           # WebDAV 同步（原生/代理双通道）
  aistore.js        # AI 后台任务全局 store
  aigen.js / ai.js  # AI 出题与讲题
  pdfextract.js     # PDF 提取与切章
  importers.js      # 题库格式解析与判分
android/            # Capacitor 安卓工程
cloudflare-worker.js# 静态托管下的 WebDAV 跨域代理（可选自部署）
docs/PRD.md         # 产品需求文档
examples/           # 示例题库
```

## 数据与隐私

- 无账号系统，无服务器上传；学习数据只存在：**你的设备**（IndexedDB）与**你自己的网盘**（同步文件，可选）
- AI 的 API Key 只存本机 localStorage，不进入同步备份
- 定期用「设置 → 导出全部数据」做备份
