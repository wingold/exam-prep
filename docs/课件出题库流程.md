# 课件出题库流程

把 `D:\study\<科目>` 下的课件 PDF 转成本应用可导入的题库 JSON。
三个脚本各管一段，互相解耦：抽取 → 出题 → 合并校验。

## 1. 抽取文本

```bash
node scripts/extract-pdf-text.mjs "D:/study/城市管理学"
# → .exam-tmp/pdf-text/*.txt，一个 PDF 一个文件
```

- 输出是**按行聚好的纯文本**（按 y 坐标聚行，避免整页挤成一行），直接读就能用。
- 脚本会按「每页平均字数」判断文字层是否缺失：扫描件抽出来是空的，会打 ⚠ 标记。
  遇到扫描件只能先用 OCR 或向老师要文字版，别硬啃。
- 讲义类 PDF 常见「一页一屏」的排版，正文字数少但信息密度高，不要被「500 页只有 4 万字」骗到。

## 2. 按章出题（人/AI 写片段）

片段目录：`banks/_fragments-<课程代码>/`，**一个文件一章**，内容是一个题目数组。

```
banks/_fragments-01680/
  01-第一章-第二章.json
  02-第三章-第四章.json
  ...
```

为什么按章拆：上百道题写进单个文件，一个逗号错了就得重写全篇，改一章也要通读。
分片之后合并时统一校验，坏了一片只改一片。

每题字段：

```json
{
  "type": "single",
  "chapter": "第一章 导论",
  "stem": "题干",
  "options": ["A 项", "B 项", "C 项", "D 项"],
  "answer": ["B"],
  "analysis": "解析：考点依据，写清楚为什么其余选项错",
  "difficulty": "重点"
}
```

出题口径（按课程卷面来，别套别的科目）：

| 题型 | 要求 |
|---|---|
| single | 恰好 4 个选项，answer 1 个字母，干扰项要有迷惑性（把易混概念当干扰项） |
| multi | 4-5 个选项，answer ≥2 个；错误选项用「说反了」或「张冠李戴」制造 |
| short | `options: []`，answer 写成「（1）…（2）…（3）…」，只给要点不展开 |
| essay | `options: []`，answer 先给要点，再说明每个要点展开什么 |

- 题目必须能在讲义原文里找到依据，**不要补充教材以外的知识**；解析里带上原文口径。
- 同一考点不要出两遍（合并脚本会按「题型＋题干」去重，但换个说法就查不出来）。

## 3. 合并 + 校验

```bash
node scripts/merge-bank-fragments.mjs banks/_fragments-01680 \
  -o "banks/城市管理学-01680-精讲题库.json" \
  --name "城市管理学 01680 · 精讲题库" --subject 城市管理学 \
  --note "据本人课件（精讲一~九，14 章）整理"
```

校验项（任一条不过直接报错并指出「哪个文件第几题」）：

- `type` 必须在 `src/questiontypes.js` 的注册表内
- single/multi：≥4 个选项、无空项、无重复项、答案字母在选项范围内、单选恰 1 个答案、多选 ≥2 个
- 主观题：`options` 必须为空、答案合并成 1 条且不少于 10 字
- `chapter` 不能为空（否则导入后会回落到科目名，章节统计全乱）

最后按「第 X 章 → 题型」排序输出，并打印题型/章节统计。

## 4. 导入前自检

```bash
node --input-type=module -e "
import fs from 'node:fs'
import { parseJson } from './src/importers.js'
const r = parseJson(fs.readFileSync('banks/城市管理学-01680-精讲题库.json','utf8'))
console.log(r.bankName, r.questions.length)
"
```

这一步走的是**应用真实的导入解析器**，能提前发现「导入后题干为空」「答案格式被归一化成别的样子」这类问题。
过了再进题库页「导入题库」，不会白导一遍。

## 5. 已知限制

- 案例题（材料题）不出：主观性太强，判分只能自评，且组卷用不到。
- **各科卷面不一样，模板不能共用**：00261 行政法学是 30/5/5/3/1（无案例，组卷满分 80）；
  01680 城市管理学是 20/10/5/2（无名词解释，案例 1×15，组卷满分 **85**）。
  模板定义在 `src/questiontypes.js` 的 `TEMPLATES`，考试页会按题库的科目/题库名自动匹配，
  猜不到就沿用上一次选择 —— 新科目接入时**必须在这里补一条模板**，否则组卷会提示错误缺题。
- 讲义只讲考点、不给习题，所以题库全部是「按讲义内容改造编题」，不是原题；做过真题后要回看讲义核对口径。
- 同一个题库要支持多套卷，题量至少要是卷面题量的 2 倍以上（01680 卷面 38 题、现 140 题，够组 3 套还有余）。
